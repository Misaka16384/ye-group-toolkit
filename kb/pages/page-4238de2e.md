## 💻 电脑端连接攻略


### 1. Windows 10 / 11

1. 前往 [华为毕昇 X1 系列支持页](https://consumer.huawei.com/cn/support/printers/bisheng-x1-series/) 下滑至「驱动下载」，下载 `华为打印（激光）_Windows_XXX` 并解压运行安装程序。
2. **同局域网连接**：选择「通过局域网搜索连接」，在列表选中 `HUAWEI CV81Z-WDMp-XXXX`（带 `ip4`/`ip6` 任选其一）点击连接，客户端会自动装好官方驱动。
3. **USB 有线连接**：插上 USB 线后选择「通过 USB 连接」，遇到「打印机网络配置」页面点 **「跳过」** 即可自动装好 USB 驱动。
4. 安装后在任意软件按 `Ctrl + P` 即可打印/自动双面；打开「华为打印客户端」可使用**彩色扫描、复印与查看碳粉余量**。
- *华为笔记本快捷方式*：支持智慧互联的华为 Windows 笔记本可按 `F10` 打开「华为电脑管家」→ `我的设备 > 添加打印机` 自动安装驱动。
1. 确保电脑与打印机在同一局域网。
2. 打开 `设置 > 蓝牙和其他设备 > 打印机和扫描仪 > 添加设备`，选中 `HUAWEI CV81Z-WDMp-XXXX` 等待自动添加即可 `Ctrl + P` 打印。
- **避坑说明**：该方式默认使用系统通用 `Microsoft IPP Class Driver`，**无法使用完整扫描/复印与浓度调节**，且华为官方提示通用驱动偶发乱码、缩放变小或双面颠倒；如遇到异常，请删除该打印机并改用上面的**方式 A**。

### 2. macOS（MacBook / iMac）

- **快速免驱打印（AirPrint）**：连同一局域网 → `系统设置 > 打印机与扫描仪 > 添加打印机` → 选中 `HUAWEI CV81Z-WDMp-XXXX`，「使用」保持 **AirPrint** 添加即可（注意：AirPrint 不支持调节浓度或使用华为客户端管理）。
- **完整功能（官方客户端）**：从 [官方支持页](https://consumer.huawei.com/cn/support/printers/bisheng-x1-series/) 下载 `华为打印（激光）_Mac_XXX` 安装，选择「通过局域网搜索连接」（或 USB 连接并跳过配网）。扫描可通过系统自带「图像捕捉」或华为打印客户端完成。
  - *macOS 13+ 避坑*：若曾装过旧版驱动导致扫描窗口卡死/白屏，请先在系统设置删除旧打印机，安装最新版官方客户端后重新添加。

### 3. Linux（Ubuntu / 统信 UOS / 麒麟 KOS）

- 从 [官方支持页](https://consumer.huawei.com/cn/support/printers/bisheng-x1-series/) 下载 `华为打印（激光）_Linux_x64_XXX` 解压，在终端运行 `sudo ./install.sh`，按提示选择局域网搜索或 USB 连接（跳过配网），程序会自动向 **CUPS** 注册驱动并安装客户端。统信 UOS / 麒麟 KOS 可直接使用官方 `.deb` 包。

## 📱 手机与平板连接攻略


### 1. 手机最稳方案：华为智慧生活 App / 「华为打印」微信小程序（支持远程）

- **第一步（一次性授权）**：下载最新版 **华为智慧生活 App** 并注册/登录华为账号，请 **Jie-Yu Zhang** 通过智慧生活将打印机**共享**给你（支持扫码、华为账号或微信好友分享）。
- **智慧生活 App 打印**：接受共享后即可直接打印手机本地文档/图片、复印和扫描，且**不要求在同一局域网**，在宿舍/图书馆也能远程下发打印。
- **微信「华为打印」小程序**：完成上述共享后，在微信搜索 **「华为打印」** 小程序并登录**同一个华为账号**即可直接打印**微信聊天记录里的 PDF/Word/PPT 与相册图片**（注：小程序不能直接选手机本地文件夹文档，可先发给微信「文件传输助手」再打）。

### 2. iPhone / iPad 特别避坑提醒（iOS 17+）


> ⚠️ **iPhone 升级 iOS 17 及以上后，系统自带「隔空打印（AirPrint）」大概率会失败或提示「打印机不再可用」**（这是 iOS 协议变更导致的已知兼容性问题，非打印机故障）。
> 请优先使用 **华为智慧生活 App / 华为打印微信小程序**，或使用下方「连接打印机热点」应急打印。


### 3. 免授权 / 跨网段应急方案：连打印机自带热点或 WLAN 直连

- **方法① 连接打印机热点（Windows / iOS / Android 均适用，仅支持打印）**：
  1. 提前把待打印文件下载到手机/电脑本地（连热点期间无法上外网）。
  2. 确保纸盒有 A4 纸，**长按打印机面板「开始键」3 秒**听到「滴」声松手，机器会打出一张 **系统信息页**，上面印有热点名称（形如 `DIRECT-XX-HUAWEI CV81Z-WDMP`）和密码（*注意：打印机重启后热点密码会变*）。
  3. 手机/电脑 Wi-Fi 连上该热点（提示无法上网选继续使用；Windows 点「改用安全密钥连接」）。
  4. 手机打开文件点打印，选择 `HUAWEI`** 开头**（不要选 `DIRECT-HUAWEI`）的打印机；Windows 打开华为打印客户端通过局域网搜索即可。
- **方法② WLAN 直连（仅 Android / HarmonyOS，免输密码，不支持 iOS）**：
  - 打开手机 WLAN，文件点打印选 `DIRECT-HUAWEI` 开头的设备；此时打印机面板**网络键呈蓝色闪烁**，走到机旁**轻触一下蓝色闪烁键**听到「滴」声确认即可。

## 🛠️ 常见踩坑与快速排查

1. **校园网下搜不到打印机怎么办？**
  - 该机仅支持 2.4GHz Wi-Fi 且不支持网页认证校园网，若你的设备连在公共校园网（存在跨网段或客户端隔离），局域网扫描必然搜不到。
  - **解法**：① 切到与打印机相同的办公室路由器 Wi-Fi；② 找 Jie-Yu Zhang 共享后用智慧生活/微信小程序**远程打印**；③ 连**打印机自带热点**；④ 插 **USB 数据线**直连。
2. **面板全黑按了没反应？（深度休眠坑）**
  - 默认 5 分钟无操作进入普通休眠（发任务自动唤醒）；若未联网且超 25 分钟无连接会进入**深度休眠**（关闭无线和 USB，所有设备都搜不到），走过去**轻触触控面板亮灯**即可唤醒。
3. **双面打印选项变灰或打反了？**
  - **长边翻转 vs 短边翻转**：常规竖版论文/文档选 **「沿长边翻转」**（像书一样左右翻页）；横版 PPT 选 **「沿短边翻转」**。
  - 选项变灰通常是因为文档只有 1 页，或纸张未设为 A4 / Letter。
4. **面板指示灯速查**
  - **开始键**：白灯常亮 = 待机就绪；白灯闪烁 = 工作中；红灯闪烁 = 故障；**长按 3 秒 = 打印系统信息页**（查 IP 与热点密码神器）。
  - **网络键**：白灯常亮 = 已联网正常；蓝灯闪烁 = 有手机正在 WLAN 直连，点一下确认；**⚠️ 切勿长按 3 秒以上**。
  - **顶部三个红灯**：从左到右依次为 **缺纸**、**缺墨**、**卡纸**。
5. **卡纸怎么办？**
  - **安全第一**：请先联系 **Jie-Yu Zhang** 处理；如确需自行清理，**务必先拔掉电源线并等待冷却**（激光定影组件极烫，防烫伤），顺着走纸方向平稳轻拉，切勿暴力硬拽，打印机背面请保持至少 10 cm 散热与出纸空间。
