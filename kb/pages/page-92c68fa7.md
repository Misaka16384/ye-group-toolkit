> 🧭 **先选对报销方式：线上电子网审 vs 线下打印投单**
> - **方式一：在线电子网审（全线上无纸化，强烈推荐）** — 只要**没有纸质票据原件**（所有发票、支付记录、住宿清单、会议通知均为电子 PDF 或截图），优先走电子网审：**不用打印确认单、不用手写签名、不用去中山楼投单**，全程线上审批并打款。
> - **方式二：线下打印投单** — 如果包含**任意纸质票据原件**（如纸质增值税发票、蓝底纸质航空行程单、纸质火车票/的士票等），则无法走全线上，请按本文下半部分「方式二」打印签名并前往投单区投递。


# 方式一：在线差旅费报销（电子网审 · 全线上无纸化）


## 1. 入口与表单选择

1. 登录 [中山大学统一门户](https://portal.sysu.edu.cn/#/index) → 进入财务系统，或直达 [中山大学财务信息门户](https://cwxt.sysu.edu.cn/#/home/index) → 点击 `网上报销`。
2. 左侧菜单进入 `网上报销 → 我的报销`，点击上方 `新增` → 选择分类 `差旅&来访` → 选择 `国内差旅费2024`（以系统当年最新年份模板为准）。
  - *其他常见差旅模板区分*：`跨校区差旅费`（异地校区点对点出差）、`国（境）外差旅`（含港澳台及境外）、`陆地/海洋野外考察差旅费`；若通过学校 **差旅平台** 预订机票/酒店，须在差旅平台直接报销或使用 `差旅平台领取补助`。

## 2. 七步填报向导逐项详解

系统顶部共 7 步：`基本信息`** → **`业务明细`** → **`报销附件`** → **`情况说明`** → **`支付设置`** → **`项目开支`** → **`提交网报`。


### 第 1 步：基本信息

- **投单点**：必选归属校区（如广州校区南校园 / 北校园 / 东校园、珠海校区、深圳校区；即使全线上电子网审也需选择）。
- **账套/经费**：按项目编号格式单选 `中山大学`（格式 `00000-00000000` 带横杆）或 `中山大学·深圳`（格式 `00000*00000000` 带星号）。
- **处理流程勾选（最关键！）**：
  - ✅ `提交网上审批`（必选，导师线上审批，无需纸质签字）
  - ✅ `电子网审模式（全线上）`（仅限无附件或全部为电子附件时勾选；勾选后无需打印确认单与投单）
- 填写 `经办人`、`联系人`、`附件张数` 与 `事由`（系统支持绑定微信/短信接收进度通知）。

### 第 2 步：业务明细

- **出差事由**：按实际勾选标签（如 `会议`、`调研`、`培训`、`学术交流` 等）。
- **出差人员**：分别录入 `校内人员`（教工/学生）与 `受邀校外人员`（如有）。
- **经费来源勾选（强烈注意）**：若使用导师的科研项目经费，请勾选 `只使用竞争性科研经费开支`。
  - 勾选后城市间交通费与住宿费标准提高，且同一行程内同一出差人的住宿费可在实际住宿天数的规定标准总额内统筹使用。
- **出差行程与补助规则**：
  - 多次往返同一地点须按次数逐一添加行程；行政公务出差不得购买超级经济舱、优选一等座等超标席别。
  - 补助默认为参考标准：若对方单位负担伙食或市内交通，须选择 `据实报销` 或 `取消或减少补助`（伙食按每人每正餐 40 元核减、市内交通按每人每半天 40 元核减；受邀校外人员不计发补助）。
- **常见费用拆分项**：`城市间交通费`、`住宿费`、`市内交通费`、`交通补助`、`出差伙食费`、`会务费/培训费`（需附会议/缴费通知）、`交通保险费`（仅限当次交通意外险，每份最高 50 元，延误险不可报）、`订票手续/行李托运费` 及零星开支。
- **特殊情况勾选**：若存在「无城市间交通费/交通票不连贯/无住宿发票」「对方承担交通住宿」「自驾往返」等情况，务必勾选对应复选框并在第 4 步说明。

### 第 3 步：报销附件（全线上过审核心）

系统会根据第 2 步的行程自动生成对应上传槽位，右侧提供 `资料上传结果提示` 面板标明必填项（带 `*`）和提醒项。

- **上传格式超省心**：发票建议直接传电子发票 PDF；**支付记录、订单截图等可直接上传图片，系统会自动转换为 PDF** 归档（无需提前手动拼接）。
- **课题组已过审单据的典型附件清单**：
  1. **电子发票类**：去程/返程机票或高铁电子发票（全电发票 PDF）、酒店电子发票、会议注册费电子发票。
  2. **支付记录（极易漏传！）**：系统规定 **单笔支付超过 1000 元人民币（或等值外币）必须提供支付记录**（微信/支付宝/银行卡付款截图均可，上传后自动转 PDF）。
  3. **住宿清单（三选一规则）**：若酒店发票备注栏未写明「住宿天数/时间、人数/房间数、单价」，须提供宾馆出具的住宿清单或携程/美团等网上订单详情截图（或填写《住宿清单》）。
  4. **其他资料**：会议通知、会议日程/手册 PDF、USC 出差报批/报备证明（如需）。
  5. **关联合同（如有）**：已在学校合同系统归档的合同次日可直接关联，无需重复上传。

### 第 4 步：情况说明

如实填写特殊情况说明即可。例如：

- 住宿天数少于实际停留天数（如首晚与同学合住未开票、中途换房等）；
- 未乘坐公共交通工具、行程日期不完全连贯等。
（业务明细页也提供《中山大学财务报销情况说明书》Word 模板下载。）

### 第 5 步：支付设置

- 常用方式：`个人转卡`、`公务卡`（可直接关联消费记录）、`对公汇款`、`冲账`。
- **银行卡提醒**：个人转卡建议使用 **一类银行卡**，避免二类户日 1 万 / 年 20 万限额导致入账失败；单笔 ≥ 1000 元不得使用现金。
- **学生转卡必填项（不用公务卡原因）**：在 `无法使用公务卡人员` 列选择 `不具备办卡资格（学生、离退休、劳务派遣、附属医院人员）或暂未办（领）卡的人员的公务支出` → 子项选择 `学生`。

### 第 6–7 步：项目开支 & 提交网报

- 按经济分类（国内差旅费科目 `3021101`）新增导师对应科研经费项目并分配金额，核对无误后提交（预算自动冻结）。

## 3. 提交后的线上审批流与退单处理

- **正常审批流（全程零打印、零跑腿）**：
`制单提交` → `提醒导师（项目负责人）网上审批` → `系统自动收单并分配财务审核员` → `审核员在线核准并生成电子凭证` → `财务打款到账`。
  - *确认标志*：进入该单汇总页，顶部应显示 **「电子网审模式，不需要打印确认单，提交后请提醒审批人网上审批」**。
- **被财务标为「问题单」怎么办？（线上直接补材）**：
  - 最常见原因例如漏传单笔超 1000 元的酒店/机票支付记录或住宿清单。
  - **无需线下投递**：直接打开该报销单详情页，点击 `补充附件` 补传缺失 PDF/截图，然后点击 `完成补充附件`，审核员在线复核通过后即可继续出凭证打款。
- **导师点击「审批不通过」怎么办？**：
  - 系统约 2 分钟内自动将单据退回并**自动解冻项目预算**，直接在 `我的报销` 里对原单点 `重新修改` 或 `复制新增` 重新提交即可。
